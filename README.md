## 🧭 How I design prompts

- **No fabrication** — never invent data, references or DOIs; unknowns are flagged as TBD.
- **Human in the loop** — validate before advancing; experts sign off on every output.
- **Structured deliverables** — canvases, checklists and tables instead of loose chat text.
- **Ask less, propose more** — minimum questions to the user, maximum useful draft.
